How this works

Each phone embeds the actual wireframe file via an iframe at a fixed 375×812px viewport (iPhone 13/14 standard size), rather than a separate copy — so these mockups always reflect the current, real wireframe content. Scroll inside any individual screen to see the rest of that page; the layouts already reflow to a single column at this width since the underlying CSS uses flex-wrap.
