What this page is

This replicates the real, already-built SwiftUI iOS app exactly: a two-tab layout (Quick Check / Browse All), a native nav bar, an always-visible disclaimer, a search field with live suggestions, and the app's actual widgets — including details a casual glance would miss, like the traffic light using red/orange/ green/gray (not yellow) and the degree-of-interaction chart only lighting up the single bar matching the current value rather than filling cumulatively. It's included here as the fixed reference point that every wireframe below is a proposed alternative to, not a replacement of.
